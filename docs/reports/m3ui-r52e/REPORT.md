# 开场：12 秒 + 连续渐隐 + 每行 5 秒

## 时间轴（实测）

| 时间 | 阶段 | 结果 |
|---|---|---|
| 0–2.5s | 光环出现、加速 | 金色 |
| 2.5–9.5s | 转红并停留 | 红色，有体积 |
| 9.5–11.7s | 连续渐隐 | 不断裂，整体变淡 |
| 11.7–12s | 空 | 约 0.3s 留白 |
| 12–17s | **星星之火可以燎原** | 5 秒 |
| 17–22s | **hello，一束光** | 5 秒 |
| 22s | 首页 | 遮罩移除 |

## 改了什么

1. **时长 3.6s → 12s**：用**分段映射**而不是线性拉伸。
   `[[0,0],[2500,1150],[9500,1605],[11700,2130],[12000,2400]]`
   —— 让红色阶段真的停留，而不是一路滑过。
2. **断裂感**：消散原来是"按段跳过"（`vis()` 返回 0 就整段不画），现在是
   `1 - dis*(0.92 + 0.08*wave)` 的**连续淡出**，每段都画，只让 alpha 走低。
3. **红色变细**：开场三层从 `6.5/2.6/0.95`（alpha 0.030/0.075/0.42）加到
   `10/4/1.5`（0.055/0.14/0.62），红色现在有体积，不是细线。
4. **文字每行 5 秒**，渐显 600ms。

## 跑完发现的问题

1. **第一版 11 秒全白**：线性映射让光环在 10.5s 就消失，留 1.5s 空白。已用分段映射修掉。
2. **红色偏细**（断裂感来源之一）→ 已加厚。
3. **消散有碎片**→ 已改为连续淡出。
4. **仍有约 0.3s 空白**（11.7s 环消失 → 12s 出字）。如果要完全无缝，可以把文字提前到 11.5s 开始淡入。
5. **总长 22 秒**（12 + 5 + 5）。对"开机"来说偏长；如果嫌长，最省事的做法是让两行各停 3 秒 → 18 秒。
6. **跳过按钮在文字阶段仍显示**，位置在左上，不压字，但如果你希望出字后立即隐藏，我可以让它随光环一起淡出。
