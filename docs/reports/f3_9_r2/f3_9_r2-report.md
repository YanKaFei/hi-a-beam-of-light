# F3.9-R2 · 有机光隙真实桌面实装验证

分支：`f39r2-aperture-experiment`。生产默认仍是 `paintBead`，回滚 = 一个环境变量。

**本轮判定：实验成功，性能有一项未收口。**

---

## 1. 渲染器切换（可回滚）

`FIRSTLIGHT_LIGHT_STYLE=legacy|aperture|organic|original`，默认 `legacy`。

运行时实测：

| 启动参数 | probe.layerModel | probe.lightStyle |
|---|---|---|
| 不设 / `legacy` | `bead` | `legacy` |
| `aperture` | `aperture:aperture` | `aperture` |

- `paintBead` 一行未改。
- 两个渲染器吃同一份 `specOf(level)`，**业务状态不由渲染器决定**。
- 面板侧同源：`light_style` 命令同时驱动桌面光点与「我的光」里的 44px 符号。

## 2. 真实桌面截图

`desktop-legacy.png` / `desktop-aperture.png`：132×132 窗口在真实桌面上，裁切后 2×。

- 旧珠：一颗灰白玻璃珠，浮在壁纸上，像贴纸。
- A2：一块深石墨的、带缺口的方形体，中心一点暖光。**它不是"珠子"，是一个物体。**

这是本轮最关键的观感差异：旧符号像"渲染出来的球"，新符号像"被放在桌面上的东西"。

## 3. 尺寸矩阵（`size-matrix.png`）

真实 canvas 渲染（WebKit），16/24/32/44/64/96 × 暖白/深灰/纯黑。

- 16–24px：两者都退化成一个点；A2 是「深方块 + 亮点」，旧珠是「灰球」。
  **A2 的轮廓在 24px 更像一个被设计过的东西，不是默认渲染物。**
- 44px：A2 的缺口开始可见，是其唯一的小尺寸身份线索。
- 64–96px：A2 的缺口与暖光核心构成清晰构图；旧珠是均匀渐变。

## 5. 轮廓补偿实验（`rim-compensation.png`）

补偿是**1px 浅色描边的 alpha**，不是明度乘数：

| rim | 深灰底 | 纯黑底 | 判断 |
|---|---|---|---|
| none | 边界融进背景 | 几乎消失 | 不可用 |
| **8%** | 边界隐约可辨 | 轮廓成立 | **采用** |
| 16% | 明显 | 明显，接近描边 | 上限 |
| 24% | 像贴纸 | 像贴纸 | 过度 |

结论：8% 是能保住轮廓又不产生"白边/霓虹环"的量。

## 6. 施工中修掉的两个真问题

1. **缺口画成了大三角**：第一版 `destination-out` 用了 17° 张角、0.80R 深度，
   桌面上是一个白色大楔子。已收窄到 6.5° / 0.88R —— 现在是"缺口"，不是"缺角"。
2. **缝隙必须默认关闭**：0.42 alpha 的浅色缝在 96px 变成"裂纹瓷砖"，
   与设计轮"细线结构熬不过缩放"的结论一致。改为默认 `seamsMinSize=9999`，
   需要对照时改回 32 即可。

## 7. 性能（两次测量，第一次作废）

第一次测量时上一个脚本崩溃留下了 2–3 个实例，`leftover process = True`，数字全部污染。
清理后重测（进程数 0）：

| | aperture | legacy |
|---|---|---|
| 空闲（动效）CPU | 0.030% | 0.017% |
| 安静模式 CPU | **0.103%** | **0.010%** |
| RSS | 113.5 MB | 113.3 MB |
| 20s 增长 | −3.5 MB | 0.0 MB |

**未收口项：安静模式下 aperture 是 legacy 的约 10 倍（0.103% vs 0.010%）。**
绝对值仍远低于 1%，但这是一条尚未解释的差异——不能因为"反正很低"就当作通过。
下一次需要单变量复测（同一台机、同一时段、各跑 3 次取中位数）后才能下结论。
