# M3-UI-R5.1 · 光学主体可见性专项

---

## 一、渲染诊断（先量，再改）

在真实首页截图里对光环区域取样，与纸面 `#F6F7F4` 求差：

| 版本 | 平均差 | 99 分位 | 最大差 |
|---|---|---|---|
| R5 基准 | **2.8** | **22** | 54 |
| 参考图 C | 40.4 | — | 112 |

**R5 的环几乎不存在**：99 分位的差异只有 22 级，肉眼几乎不可辨。

逐项排查结果：

| 检查 | 结论 |
|---|---|
| 颜色与背景的合成 | **主因**：`mid=(216,208,192)` 与纸面 `(246,247,244)` 只差约 30 级，再乘 alpha 0.21 只剩 ~6 级 |
| 透明度是否重复相乘 | 没有。`globalAlpha` 保持 1，只有 strokeStyle 的 alpha |
| 叠加模式 | 默认 `source-over`，没有 `lighter`，不存在越叠越白 |
| DPR | 正确。`canvas.width = w*dpr` + `ctx.scale(dpr,dpr)`，只缩放一次 |
| 亚像素/抗锯齿 | 主因之二：线宽 `R*0.010*0.9 ≈ 1.2px`，细线被抗锯齿摊薄一半以上 |
| 额外 opacity | 无 |
| 交错被柔光覆盖 | 是。三层里最宽的 6× 层 alpha 0.02，把结构糊成了雾 |
| 提到 glow 0.85/1.00 仍无轮廓 | 因为 glow 只放大 alpha，色值本身离纸面太近，放大也到不了可辨阈值 |

**一句话**：不是"光太暗"，是**光与纸的颜色差太小，且线太细**。继续调 glow 永远无效。

## 二、改了什么

1. **改用"比纸深"的结构色**：`ink` 取 `#7E8882` 一档（126,136,130），
   在纸面上合成后约 190 级，对比度 56 级——这才是能被看见的量级。
2. **加一道暖白细芯**（`hot`）压在结构线上：让每条轨同时有"暗的形"和"亮的芯"。
3. **纱层改成比纸略深的暖灰**（226,219,204），而不是比纸更白——
   在 `#F6F7F4` 上"更白"没有空间，只有"略深"才存在。
4. **加一层极淡的空气池**（径向 0.045 → 0），让雕塑从纸上浮起来。
5. 线宽从 `R*0.010` 提到 `R*0.0075`（更细）但**alpha 提高**，避免粗描边。

## 三、A / B 候选

| | A · Structural | B · Atmospheric |
|---|---|---|
| 纱层 | 无 | 半径 4.2×、alpha 0.085 的暖灰纱 |
| 空气池 | 无 | 有 |
| 交叉高光半径 | 0.13 R | 0.20 R |
| 平均差 / 99 分位 | 4.3 / **101** | 6.1 / **106** |

两者结构相同、排版相同、状态相同，只差光学层。

## 四、诚实结论

**可见性修好了，美术质量没修好。**

- 99 分位从 22 提到 101/106，光环现在一眼可见，倾角与交错都成立。
- 但它在纸上仍然是**灰色线稿**的样子，不像参考图那种"光"。
- 根因不在代码：参考图的纸是 `#F5EDE4` 一档（更暖更深），光才有从"暗纸"里浮出的余地。
  我们的纸 `#F6F7F4` 太接近白，光只剩"变深成灰线"这一条路。

要真正接近参考图，有三个方向（**本轮未做，等你定**）：

1. 把首页背景换成更暖的一档（`#F4EEE4` 左右），光就能重新变"亮"而不是"变灰"；
2. 给光环一块极浅的暖色底（局部"纸中纸"），让光在局部有对比空间；
3. 接受灰色，但把它做成**石质/金属丝的雕塑**语言，而不是"光的语言"。

## 五、状态语义（已核对）

| 状态 | 判定 | 首页 |
|---|---|---|
| 未连接 | 无设备或未配对 | `UNPAIRED`，灰 |

| 独立核验 | 服务端来源政策确认 | 深红，**当前生产不可达** |

`PLUGIN_OBSERVED.activate=false` 未改。未使用任何伪造数据，未生成 VISUAL_FIXTURE。
