## 任务一：呼吸动画为什么没有变化

### 根因（代码级，已确证）

`pages/mine/mine.js` 的 `onShow` 里只调用了 `renderLight()`，**它只画一帧**。
真正的循环 `startLight()` 只在 `onTapLight()` 里被调用。

所以静置状态下：

- 没有任何 `setTimeout` 循环在跑（`raf: false`）
- `t` 永远是 0
- 每一帧都是同一张静态图

**这不是 GIF 编码问题，也不是截图缓存问题**：我逐像素比对了提交的 8 张
`breath-*.png`，最大差 **0**、不同像素 **0**。图确实是一样的，因为根本没有第二帧。

### 修复

1. `onShow` 在首帧绘制后调用 `startLight()`。
2. 时间改为**墙钟驱动**（`Date.now()` 差值，上限 120ms），不再假设每帧 33ms。
3. 增加 `__draws` 计数与 `__lastTick`，让"循环确实在跑"可被外部验证。
4. `stopLight()` 清空 `__lastTick`。

### 已验证的部分

在旧包里手动调用 `startLight()`，400ms 内 **13 次绘制、t=399** ——循环本身是好的，
坏的只是"没人去启动它"。

### 未完成

新的包未能进入模拟器：IDE 没有重新编译（`String(p.startLight)` 里不含新特征串 `__lastTick`，
改 app.json 触发也没用）。**多帧取证需要一次手动编译（⌘B）后才能拍**。
在此之前我不拿旧图充当证据。

## 任务二：静态美术质量的停止门槛

一次对照审计，不再调参。三个判断：

### KEEP

- **机制**：先场后丝、三级丝层、几何求解交点 —— 这套结构是对的，保留。
- **色温体系**：静默暖灰 / 观察暖杏的映射正确，且不冒充点亮。
- **无边界光场**：半径与 alpha 归零的边界处理正确，实测无矩形、无裁切。

### LIMITATION

**Canvas 2D 的描边画不出参考图 C 的材质。** 具体三处：

1. **R2 在 390px 下为什么仍偏淡**：因为"丝"是一个 stroke，亮度上限由 alpha 决定；
   参考图里的亮丝是**多条纤维叠加后的内部散射**，中点可以接近纯白，
   而我们的单笔 stroke 到 0.7 就已经发灰。
2. **哪些亮丝被吞没**：`WISP` 三条（0.085/0.05/0.04 alpha）在场较亮处基本不可见；
   `SECOND` 两条在 390px 下也只能算"隐约"。
3. **有没有真正的第一视觉焦点**：有，但**很弱**——lead 丝的焦点包络在正常观看距离下
   仍只是一个"稍微亮一点的弯"，不足以抓住第一眼。
4. **暖金夹具为什么缺少能量跃迁**：因为 `lift` 只放大 alpha 与场色温，
   而"跃迁"需要**局部动态范围**（亮部更亮 + 暗部更暖），单靠整体 alpha 提不上去。

### NEED_NEW_ASSET

要让材质真正接近 C，需要**位图级光学基底**：多层高斯叠加、真实散射、局部过曝可控。
那就是 B2-2 的路线（已暂停）。Canvas 继续调参数**不会**跨过这道门槛。

**结论**：B2-1 的天花板在"精致但偏淡的场 + 可辨的丝"，
再往上不是参数问题，是渲染介质问题。**建议停止在 B2-1 上继续调参。**
