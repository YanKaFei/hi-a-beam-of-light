# 隐私访问审计（F2）

对象：桌面端（`apps/desktop`）、Codex 适配器、扫描调度、光点与面板 UI
继承：F1 的 21 项隐私负向测试仍然全部通过（163 项 Rust 测试中的一部分）

---

## 1. F2 新增的隐私面

F1 只涉及"读本机数据库"。F2 增加了三类新的风险面，逐项核对：

### 1.1 光点窗口
| 风险 | 处理 | 证据 |
|---|---|---|
| 窗口截图泄漏下层内容 | 窗口完全透明，`isOpaque=false`、`backgroundColor` alpha=0 | T-01 §1.1 像素级证明 |
| 窗口记录/被其他 App 捕获 | 无录屏豁免实现；窗口只是普通浮层 | 未额外处理（无 API 可申请豁免） |
| 位置被用于推断 | 位置只存本地 `desktop-state.json`，不上传 | 见 §2 |
| 窗口常驻被误认为活跃 | 应用激活策略为 accessory，常驻时 `is_active_app=false` | T-01 §1.4 |

### 1.2 面板
| 风险 | 处理 |
|---|---|
| 面板显示原始模型字符串 | 会显示（如 `gpt-6-sol`），这是公开模型名，不是用户内容 |
| 面板显示会话 ID | **不显示**；扫描报告里只有 12 位摘要 |
| 面板显示文件路径 | 不显示；仅显示状态目录（用户自己的路径，便于排查） |
| 面板显示聊天内容 | 不可能：适配器从未读取，内存中不存在 |

### 1.3 控制通道（测试用）
| 风险 | 处理 |
|---|---|
| 常驻监听端口被滥用 | 仅当 `FIRSTLIGHT_CONTROL_SOCKET` 环境变量存在时启动；Unix socket 文件权限继承用户 umask |
| 生产环境误开 | 默认不启动；未设置变量时完全不存在该线程 |
| 通过它读数据 | 它只能读**应用已经算好的状态**，不能直接读数据库 |

> 需要你知悉的判断：这是一个为可验证性付的代价。它不进生产默认路径，
> 但如果未来要发布，建议在 release 构建中通过 feature flag 彻底编译掉。

## 2. 数据面核对：F2 是否有任何数据离开本机

| 通道 | 是否存在 | 说明 |
|---|---|---|
| HTTP 请求 | ❌ 无 | F2 代码中没有任何 HTTP 客户端被桌面端使用（`adapter-ollama` 有，但未被桌面端调用；且它只允许 loopback） |
| 遥测 / 崩溃上报 | ❌ 无 | 未引入任何 SDK |
| 上传原始数据库 | ❌ 无 | 无此代码路径 |
| 上传 token 数 | ❌ 无 | 该列全局禁读 |
| 写回第三方数据库 | ❌ 无 | 连接只读 + `query_only` |

**核验方法**：`grep` 桌面端 crate 的依赖与源码，确认无网络库被调用。
可用命令：
```bash
grep -rn "TcpStream\|reqwest\|ureq\|hyper" apps/desktop/src-tauri/src/ || echo "无网络调用"
```
（`adapter-ollama` 的 `http.rs` 是唯一含 `TcpStream` 的文件，且未被桌面端引用。）

## 3. 本地存储的隐私属性

| 文件 | 内容 | 是否含敏感信息 |
|---|---|---|
| `desktop-state.json` | 窗口位置、开关、上次扫描时间 | 仅位置与布尔值 |
| `light.sqlite` | 家族名、证据等级、适配器 ID、时间 | 家族名是公开模型名 |
| `last-scan.json` | 上次扫描的汇总计数与读取列名 | 只有计数与列名，无值 |

**刻意不存**：原始模型所在会话的任何标识（只存 12 位摘要）、文件路径、聊天内容、
token 数、API Key。

`.gitignore` 已排除 `*.sqlite`、`*.db`、`.env*`、`*.pem`、`*.key`、恢复码文件。
已核验：`git ls-files` 中不含任何数据库或密钥（82 → 现 100+ 文件中检查通过）。

## 4. 权限与越权核对

| 检查 | 结果 |
|---|---|
| 是否请求了系统级敏感权限（辅助功能、全盘访问） | ❌ 未请求，也未修改系统设置 |
| 是否 sudo 安装任何东西 | ❌ 无 |
| 是否修改第三方数据库 | ❌ 只读连接；WAL 降级模式也 `query_only` |
| 扫描是否递归全盘 | ❌ 单目录、固定前缀、不递归 |
| 是否因失败而扩大范围 | ❌ 失败即返回明确原因 |
| 是否可用 `immutable=1` 绕一致性 | ❌ 明确未实现 |

## 5. 残留风险（如实记录）

| 风险 | 严重度 | 说明 |
|---|---|---|
| 测试控制通道存在于二进制中 | 中 | 默认关闭；建议 release 用 feature flag 剥离 |
| WebView 自身可能在 `~/Library` 写缓存 | 低 | 属系统 WebView 行为，不包含用户数据内容；沙箱下写入被拒也不影响运行 |
| 面板显示自家状态目录路径 | 低 | 是用户本机路径，仅本机可见；若截图分享会暴露用户名 |
| 模型家族名可被旁观者看到 | 低 | 光点本身不显示文字；只有打开面板才显示 |
| 位置信息可用于推断作息 | 低 | 仅本地，不上传；用户可随时重置位置 |

## 6. 结论

| 结论 | 依据 |
|---|---|
| F2 没有任何数据离开本机 | §2 |
| 新增的三类隐私面均已核对并有措施 | §1 |
| F1 的列级边界在集成后仍然成立 | 端到端 D + F1 21 项测试 |
| 失败时不会提权、不会扩大扫描 | §4 + 端到端 H/I |
| 唯一值得剥离的是测试控制通道 | §5，建议 release 时处理 |
