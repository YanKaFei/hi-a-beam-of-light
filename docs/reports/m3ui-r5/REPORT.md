# M3-UI-R5 · Luminous Interface 交付

回滚点：`f1a69f5`（R4.3 通过版）

---

## A. 原有版本审计结论

1. 首页是字段表：设备 / 最近观察 / 可信证据 / 管理连接，用户看到的是数据字典。
2. 三项 TabBar 长期占据屏幕，把作品压成了工具。
3. 光只是顶部一张图，不承担状态。
4. 启动动画止于"消失"，没有叙事落点。
5. 没有核心动作——用户不知道"我能做什么"。

## B. 实际完成

| 模块 | 内容 |
|---|---|
| 品牌序列 | Ignition（2.4s）→ **星星之火可以燎原** → **hello，一束光** → 首页，总长约 5.8s |
| 首页 | 顶部 FIRST LIGHT、中央 Canvas 光、**我的光**（唯一主动作）、一句真实状态、底部 `传光 · 回响 · 更多` |
| 观察交互 | 点击后：光聚拢 → 真实查询 → 逐条文字 → 结果；可取消、超时、丢弃过期响应 |
| 光的状态 | `utils/light.js` 把信任等级映射为色温/速度/辉光，七个等级各自一组 |
| 导航 | **移除原生 TabBar**，改为文字次级入口；六个页面全部保留 |

新增文件：`utils/light.js`（状态→视觉）、`utils/observe.js`（观察控制器）。
改写：`pages/mine/*`、`app.json`（去 tabBar）。

## E. 艺术质量（不自评通过）

- 首页层次成立：光 → 我的光 → 一句状态 → 次级入口。
- **光偏弱**：静默态在暖白纸上接近不可见；`glow` 已从 0.35/0.45 提到 0.85/1.00，仍然偏淡。
- 宣言字号 34px、居中、字距放松，但**没有做到"大字排版"的仪式感**，仍偏常规。
- 启动到首页的过渡尚未与首页做真正的光学衔接（上一轮的 320ms 渐显在新序列里被文字段替代）。
