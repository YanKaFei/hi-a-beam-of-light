## B. 实际修改

### 主丝精修

- 三条主丝的**权重拉开**：lead `1.00` / 交错 `0.72` / 辅助 `0.42`
  （R1 是 1.00 / 0.80 / 0.72，几乎同权）。
- 亮芯不再是**整条描边**，改成沿路径的**焦点包络**：

```js
envelope(u, centre, width) = exp(-d²/width²)   // 首尾自然消隐
```

  每条主丝只有 1 个自身焦点（`0.18 + i*0.27`），其余能量只出现在真实交点。

### 场能量

- 内场从"与中心同心"改为**偏离中心**（`+0.05R, -0.035R`），半径 `0.92R`。
- 外层大晕不放大（仍 `0.50×短边`），只压低权重，让内外能量比拉开。
- 场中心 alpha 从 0.30 提到 0.46，但**范围不变**——是"更有厚度"，不是"更大"。

### 交点重做

交点**从几何里求出来**，不是手放的坐标：

```js
crossings(mainPts[0], mainPts[1], R*0.06)  // 两条主丝折线的最近距离
```

得到参数 `u` 后：

1. 主丝在 `u` 附近用 `ENERGY.crossSpan` 的窄包络提亮；
2. 再叠一段**沿同一条曲线**的短粗高光（`0.012R` 宽）；
3. 主交点幅度 `1.0`，次交点 `0.55`。

所以交点是"光在两个方向上同时变亮"，不是两团径向模糊。

### 静默 / 暖金差异

`STATE` 表里每个等级带 `lift`：`PAIRED_IDLE = 1.00`，`LOCAL_OBSERVED = 1.34`。
差异体现在**场色温 + 丝亮度 + 呼吸幅度**，不是整页加饱和。

### 动效

- 呼吸周期 7000ms，幅度 `breathe 0.14`。
- 流动高光只跑 **lead 一条**，速度 `0.15×`，跨度 `0.06`。
- 其余两条主丝不流动——避免"扫描器"感。

## F. 自我审美评估

1. **哪条光丝成为视觉主导？** lead（`1.06 / -12°`）。权重 1.00，也是唯一有流动高光的一条。
2. **为什么它没变成硬线？** 因为它由三层构成：0.030R 的纱、0.0105R 的体、0.0042R 的芯，
   芯只在包络内出现。硬线是"一条等宽等亮的线"，它不是。
3. **能量中心在哪里？** 内场中心偏移 +0.05R/−0.035R，视觉落在光环偏左上，
   与 lead 的焦点包络位置接近。
4. **为什么外场没有形成圆斑？** 外晕四段渐变的最后一段 alpha 为 0，
   且半径 0.50×短边意味着它在画布内部就归零；填充用 `arc` 而不是 `fillRect`。
5. **交点为什么像汇聚而不是贴片？** 因为亮度变化发生在**两条丝各自的路径上**，
   形状跟着曲线走；没有独立的圆形光斑。
6. **静默与观察的差异来自什么？** 场色温（暖灰 → 暖杏）、丝亮度（lift 1.00 → 1.34）、
   焦点包络峰值，而不是全图提亮。
7. **距离参考图 C 还差什么？** 参考的亮丝更细更狠、对比更强；
   我们的静默态仍偏"雾中一条淡淡的丝"。
