## 1. 具体改了什么

### 光场

| | 上一版 | R1 |
|---|---|---|
| 结构 | 单层径向渐变 | **两层**：半径 1.05R 的暖芯 + 半径 0.50×短边的大晕 |
| 中心 | 与边缘同色相 | 新增 `fieldCore`，中心更暖更实 |
| 静默态 alpha | 0.30 | **0.46**（更厚，但不扩大到整页） |
| 边界 | 圆形，alpha 归零 | 不变，仍是数学零点，无矩形/无椭圆底板 |

### 丝的分级

原来是"8 条同权重的线"，现在分三类：

| 层级 | 数量 | 画法 |
|---|---|---|
| **主丝** | 3 | 晕（0.085）+ 纤体（0.55）+ 亮芯（0.75），三层叠加 |
| **副丝** | 2 | 晕（0.035）+ 纤体（0.30），不提亮芯 |
| **背景丝** | 3 | 单笔 0.10，几乎溶进场里，只加气氛 |

不再让所有轨迹都被同样看清——这是"线框结构"和"光学装置"的区别。

### 静默态重画

- 场：中性偏暖灰 `[214,205,192]`，核心 `[222,208,190]`
- 丝：近白 `[253,252,248]`，比场亮 8–14 级
- 交点：两处极弱能量，静默时几乎只剩一点柔光

**不是灰线稿，也不是已点亮。** 它是"一束还没被点亮的暖灰光"。

### 与标题的关系

`.light-wrap` 44vh → **40vh**，`.call` 上移 margin −6vh → **−12vh**。
光环与「我的光」现在读作一个整体，不再是上下两个版块。

## 3. 我的评估（等你否决）

**达成**：
- 第一眼是"一片有光的地方"，不是几条灰线。
- 场无边界，中心有厚度，四周自然回到纸色。
- 丝有明确主次，不再平均。
- 光与标题成为一个主体。
- 暖金夹具明显更有能量，且不刺眼。

**仍未达成**：
- 参考图的亮丝更集中、更"细而狠"；我们的主丝偏软。
- 静默态与暖金态的差别主要在色温，能量差还可以再拉开一点。
- 场的大晕在页面中部仍能隐约看到边界方向的亮度变化（极轻微）。
