## 1. 安静模式 CPU 差异：**没有复现**

交替实验 Legacy → A2 → Legacy → A2 → Legacy → A2，每次清理残留实例、预热 7s、
同窗口位置、同业务状态（未扫描）、安静模式开启后采样 5 次 × 2s。

| 运行 | 中位数 | 区间 |
|---|---|---|
| legacy #1 | 0.0135% | 0.0022–0.0989 |
| aperture #1 | 0.0279% | 0.0012–0.0698 |
| legacy #2 | 0.0236% | 0.0019–0.3276 |
| aperture #2 | 0.0029% | 0.0018–0.1736 |
| legacy #3 | 0.0024% | 0.0013–0.0318 |
| aperture #3 | 0.0020% | 0.0017–0.0199 |

**合并中位数：legacy 0.0135%，aperture 0.0024%。** 区间高度重叠，单次尖峰（0.33% / 0.17%）
主导均值。R2 报告的 "0.103% vs 0.010%" **在受控条件下不再出现**，判定为当次测量的污染。

### 渲染诊断（每次运行结束时读取计数器）

| 指标 | legacy | aperture |
|---|---|---|
| 安静模式下 draw 调用 | **0** | **0** |
| 安静模式下 requestAnimationFrame | **0** | **0** |
| 符号烘焙次数（corePaint） | 1 | 1 |
| 残留主进程数 | 1 | 1 |

结论：安静模式下动画**确实暂停**，符号只烘焙一次，没有多余 rAF 或重复视觉更新。
不需要为了 0.01% 牺牲视觉品质。

原始数据：`cpu-experiment.json`

## 2. 七个真实桌面状态

全部来自运行中的 App（`states/` 下每态一张悬浮光点 + 一张面板）。传光三态由
真实本地服务端驱动，E3 证据为**测试夹具（TEST / SYNTHETIC）**。

| 状态 | 面板文案 | payload |
|---|---|---|
| 未点亮 | 寻光者 / 0 家族 | 无扫描 |
| 首次点亮 | **初明者 / 1** (`gpt`) | scan ok, families=['gpt'] |
| 多次成长 | **启迪者 / 2** (`claude`,`gpt`) | scan ok, families=2 |
| RECEIVED | 「对方已经接收，等待你确认。」 | state=RECEIVED |
| LEARNING | 「关系已建立。等对方产生真实的 AI 使用后才会点亮。」 | state=FORMED |
| ACTIVATED | 「这束光已经点亮。」 | `{"kind":"FIRST_LIGHT","state":"ACTIVATED","already_activated":false}` |
| 回响 | 回响页显示事件与时间 | echoes=1 |

- RECEIVED 未显示为已激活；LEARNING 未自动升级；ACTIVATED 由服务端 `complete` 返回确认。
- 发送者在传光全程称号与家族数不变（1 → 1）。

## 4. 最终品牌对照（`brand-board.png` / `brand-mono.png`）

24px（上）与 44px（下），列：暖白 / 深灰 / 纯黑 / 合成壁纸。

| | 来源 |
|---|---|
| A Legacy 灰珠 | **REAL**（真实 canvas） |
| B A2-Signature | **REAL** |
| C A2-Organic | **REAL** |
| D B1 Seed | **DESIGN COMPOSITE**（设计文件，非 App 截图） |

只看图能得出、且我认为最重要的三条：

1. **深色背景下 A2 的本体几乎消失**，只剩一点光晕和 8% 描边；而 A 与 D 因为自身发光，
   在深底上依然成立。桌面壁纸经常是深的，这是 A2 目前最实质的风险。
2. **24px 时 A2 与 C 几乎不可区分**（缺口在这一尺寸被吃掉），A 与 D 的轮廓差异反而更清楚。
3. 浅底上 A2 是四个里唯一"像一个物体"的；A 像渲染球，D 像图标。

## 6. 尚未解决的品牌风险

1. **深底失形**（见 §4-1）——8% 描边不足以让本体在深色壁纸上成立。
2. **24px 缺口不可见**，A2 与 Organic 在小尺寸无差别。
3. 仍读得出"光圈"，且方形轮廓在极简背景下可能被读成"方块按钮"。
4. 无真人识别测试：**USER_STUDY_PENDING**。

## 7. 建议

**倾向保留 A2-Signature，但必须先解决深底失形。**
理由不是审美：浅底上它是唯一具备"物体感"的方案，这是品牌识别真正的来源；
但深底上它退化为光晕，而桌面场景深底很常见，这一点不解决就不该定稿。

若下一轮无法在不动几何的前提下解决深底问题，**退回 B1 更稳妥**。
