## 二、你指出的导航问题（真 bug）

`回响` 和 `传光` 两页**根本没有返回入口**——它们从 tabBar 时代改成普通页面后，
`back` 处理函数只加在了 `paths / settings / pair` 上，这两页漏了。
从首页点进「回响」之后，用户**无法回到主页**。

修复：

- 新增 `utils/nav.js`：`goHome()` —— 有页面栈就 `navigateBack`，没有就 `reLaunch` 到首页
  （深链直接打开回响时也能回家）。
- 五个二级页（回响 / 传光 / 光路 / 设置 / 连接插件）统一在页头左侧加 **「← 我的光」**，
  与页面名并排成一组，不挤压右侧胶囊。

实测：

```
首页 → 回响 → 点「← 我的光」 → 首页   ✅
首页 → 传光 → 点「← 我的光」 → 首页   ✅
```
