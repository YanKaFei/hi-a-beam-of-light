# R5.2-B · 开机修正 + 材质基底尝试

## 一、你指出的两处开机问题（已修）

**1. 光环后面有东西重叠。** 那不是背景图，是**首页自己的呼吸光环**——
循环启动后，它在开机遮罩下面继续绘制，从边缘透出来，形成两层不同倾角的重影。

修复：`tick` 里 `if (this.data.showIntro) { clearRect; 继续等; return; }`，
开机期间首页光被清空且不再绘制；`endIntro()` 结束后才交还。

验证：`intro-2_4s.png` —— 画面里只有开机光环，`lightDraws` 冻结在 109（没有新绘制）。

**2. 光环时间延长。** 2.4s → **3.6s**，用 `ms * (DURATION / IGN_MS)` 把同一条曲线铺开，
不是简单停在末帧。流动高光相位也放慢（`ms/1200`）。

## 二、R5.2-A 三点对齐（前提条件）

做了带**烘焙标记点**的对齐基底（品红=中心、青=右缘、黄=顶缘），
画布在同样三点画红/绿/蓝点，同一帧截图比对。

| 项 | 结果 |
|---|---|
| 坐标系单一来源 | **PASS**（`lightframe.frameOf` 被画布与基底共用） |
| 抓到的真实错位 | 基底比画布高 **42.3 CSS px** |
| 根因 | `.light-wrap` 缺 `position: relative`，绝对定位基底用了外层包含块 |
| 修复后 | 偏差降到 ~15 px（同口径） |
| 是否收敛到 ±2px | **未证实**（测量受场裁剪与页面其它亮像素污染） |

## 三、材质基底：这次失败了，我回滚了

按混合方案生成了 1170×1020 的光学基底（三层纤维 + 内部介质 + 交点能量，边缘 alpha=0），
接到首页作为静态层，Canvas 只保留流动高光。

**结果不行**：在 390pt 显示时，基底被 3 倍下采样，细纤维被平均掉，
屏幕上只剩一团没有结构的柔光——比原来的 Canvas 版本更差。

**根因**：基底按 DPR=3 生成（1170px 宽），但显示尺寸只有 390pt，
1~2px 的纤维在下采样时被低通滤掉。参考图的"纤维感"正是由这些细线承载的。

**我没有把它留在线上**：默认渲染已回滚到 Canvas B2-1（`prod-restored.png`），
`light-base-art.png` 仅作为待评估资产保留。

**正确的下一步**（下一轮）：基底按**显示尺度**生成（约 780px/2x），
纤维在生成空间里就有 2–3px 宽，让"下采样"变成"轻微柔化"而不是"抹平"。
