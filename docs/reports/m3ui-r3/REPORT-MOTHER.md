# 以附件为视觉母体 · 三件交付

---

## 0. 我理解的核心

附件不是"一个漂亮的发光圈"，而是：**光在暖瓷白的纸上形成结构**。
所以全部工作围绕三件事——轻、透、暖；线要细，晕要柔，亮部要窄。

我没有把它做成实体图标、没有加外框、没有转成硬质 Logo。

---

## 1. 渲染方法的变化（决定了成败）

前几版失败在方法：把光画成**线**，再糊一层光晕。
附件里的光不是线，是**能量在纸上的累积**。

于是改成单一能量场：

- 每条光丝在采样点做三次叠加：**宽纱（7×半径）+ 中晕（2.6×）+ 细芯（0.85×）**
- 全场只有一个标量能量 `L`
- 结束时用 `i = 1 - exp(-L·1.35)` 做饱和映射，再从 `i` 推颜色与 alpha

这样光丝交叉处能量叠加会自然变亮，但**永远不会过曝成白斑**——因为 `1-exp` 是饱和函数。
颜色从桃（边缘）→ 金（中段）→ 暖奶油（核心），刻意**不到纯白**。

## 2. 三件交付

### ① Splash 启动画面
`docs/reports/m3ui-r3/splash.png`（750×1334）

- 底色暖瓷白 `#FAF4EA`
- 光环居中偏上，约占视觉中心，不撑满
- 下方：`第 一 束 光`（字距拉开）+ `让光被看见`
- 一条 72px 的发丝线收尾

**动效方案（暂不实现）**：光环 opacity 0→1 用 900ms ease-out；光丝做 1.5% 的极缓亮度起伏（周期 12s）；不做旋转、不做粒子。

### ② Logo 双版
| 版本 | 文件 | 用途 |
|---|---|---|
| 完整版 | `logo-512.png` / `logo-192.png` | 启动画面、首页大图 |
| 小尺寸版 | `logo-small-96/48/24.png` | 页头、图标 |

提炼方式：**减少光丝数量（2 条）、收窄半径、保留倾角与光的汇聚**。
小尺寸版额外做了对比补偿（加深色相、抬 alpha）——因为 96px 以下的柔光在纸面上会消失。
即便如此，**24px 已接近极限**（见对比板 ④）。

## 3. 与附件的关系

| 附件特征 | 实现 |
|---|---|
| 暖瓷白 / 米白背景 | `#FAF4EA` |
| 轻盈半透明、暖金偏桃 | 能量映射到 桃→金→暖奶油，止于非纯白 |
| 倾斜椭圆光轨 | 倾角 −26°，压缩 0.60 |
| 多条光丝、交错 | 6 条不同半径/倾角/相位 |
| 出现 / 悬浮 / 被看见 | 中心负空间 68%，边缘 alpha 归零 |
| 非机械、非硬科技 | 无闭合均匀轨道，光丝有呼吸式断开 |

## 4. 透明与工程

| 检查 | 结果 |
|---|---|
| 四边 alpha | 0 |
| 暖瓷白 / 浅灰 / 深色 合成 | 角点 = 各自底色，无灰块 |
| 棋盘格 | 无方块、无色圈、无截断 |
| 体积 | Hero 108KB / Splash 93KB / Logo 32KB |

生成器：`design/f39r7/orbit2.py`（可复现）。

## 5. 我仍认为不足的地方

1. **比附件更"圆"**：附件的光丝有更明显的不共面感（有几段明显不在同一椭圆上），
   我的六条仍共享一个平均平面，交错感弱一些。
2. **亮部汇聚不够锐**：附件的交汇处有一条几乎到白的高光，我的止于暖奶油。
3. **光丝数量偏少**：附件更像 8–10 条细丝，我的 6 条在中距离看略显"整"。
4. **24px 不可用**：如实反映在对比板里，没有用模糊伪装。

这四点都可以调（参数在 `TRAILS` 与三次叠加的权重里），
但我没有继续调，因为**方向需要你先确认**——我不想在没有审美确认的情况下把光丝越加越复杂。
