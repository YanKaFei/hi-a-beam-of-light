# M3-UI-R3A · 光之环修订 A / B

## 1. 这一轮真正改掉的东西

上一轮六条光轨**共享一个平均平面**——半径不同、倾角几乎相同，所以投影出来是"同心嵌套"，
看起来圆整、规矩，正是你指出的问题。

这一轮给每条光轨独立的：

| 参数 | 之前 | 现在 |
|---|---|---|
| 椭圆比（aspect） | 全部 0.60 | **0.80 – 1.16**（六条各不相同） |
| 倾角 | −14° ~ −33°（19° 跨度） | **−6° ~ −52°（46° 跨度）** |
| 中心偏移 | 最多 ±2% R | **±2.6% R** |

结果：光轨在左右两侧形成真正的 **X 形交叉**，不再是套在一起的椭圆。
深底合成（⑥）里这一点最清楚——你能看到几条轨道彼此穿过。

## 2. 局部光学

保留宽纱 + 中晕 + 细芯三层，保留能量场与 `1−exp` 饱和映射。
只加了一件事：**超线性抬升**

```
hot = max(0, L − 0.36)
Lp  = L + 1.25 · hot² · 6
```

它只对"已经比较亮"的像素起作用——也就是**光轨真正相交的地方**。
单条光轨不会被抬亮，所以不会出现全局 glow 增益，也不会出现白色圆点。

颜色末端从纯白退到暖白 `(255,248,232)`。
