# M3-UI-R4.2 · Ignition 最终艺术修订

---

## 1. 加速（400–1150ms）

改动集中在**局部运动高光**，没有加粗线条、没有加全局光晕。

| 项 | R4.1 | R4.2 |
|---|---|---|
| 高光长度 | 固定 0.55–1.10 rad | **0.45 + 0.95·acc**（随加速变长） |
| 高光亮度 | 固定倍率 | **0.55 + 0.9·acc**（随加速变亮） |
| 前缘/尾部 | 整段同亮度 | **拆成 7 段，前缘最亮、尾部 `(1-f)^1.7` 衰减** |

现在是"一段亮边拖着逐渐消失的尾巴沿轨迹跑"，而且跑得越来越快。

## 2. 赤红峰值（1150–1600ms）

新增一个**能量包络**：

```
peak = exp(-((ms - 1350) / 105)²)
```

在 **约 1250–1450ms** 形成一个短促的局部高潮，作用点只有两个：

1. 高光段更长、更亮（`+0.35` 长度、`+1.6` 亮度）；
2. **两个交汇点**各叠加一团暖白径向光（`rgba(255,244,226)`），半径只有 R·0.16。

没有全屏闪光，没有加红饱和度，光丝依旧是细的。

## 3. 消散（1600–2050ms）

从"硬断开"改成**沿行进方向的连续消隐**：

- 每条轨迹切成 26 段，每段按一个慢变场决定可见度：
  `keep = clamp(1.55 - dis·2.35 + field·0.55, 0, 1)`
- 段线宽同时按 `0.55 + 0.45·keep` 收细
- 因此断点是渐变的，不会出现一排孤立红碎线

## 4. 首页衔接（本轮重点）

遮罩不再"到点消失"，而是**最后 320ms 背景色淡出**：

- CSS `transition: background-color 320ms ease-out`
- 在 `total - 320ms` 时加 `.revealing` 类，背景从 `#F6F7F4` → 透明
- 真实首页在遮罩下方**同时可见**，光丝继续淡出
- TabBar 仍在动画结束后恢复（避免提前出现）

对比 R4.1：末段不再有"纯空白停顿 + 突然出现"。
