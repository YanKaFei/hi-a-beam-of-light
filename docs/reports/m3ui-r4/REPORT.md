# M3-UI-R4 · Ignition 启动动画

---

## 1. 实现方式

**Canvas 2D 实时绘制**，不是把 B 版 PNG 旋转变红。

`utils/ignition.js` 里重建了 B 版的几何：八条光轨，各自独立椭圆比（0.80–1.16）、
倾角（−6°~−52°）、半径与中心偏移——所以画面里能看到真正的交叉，
而不是同心椭圆。

每条光轨画三层（宽纱 / 中晕 / 细芯），再叠一条**沿曲线流动的高光弧**。
加速感来自这条弧的速度，而不是整个 Logo 的旋转。

`draw(ctx, W, H, ms)` 是纯函数：只依赖时间，因此每一帧都可复现、可寻址。

## 2. 时间轴（实测）

| 章节 | 区间 | 实现 |
|---|---|---|
| Awakening | 0–400ms | 整体 alpha 用 ease 从 0.15 起，光丝开始流动 |
| Acceleration | 400–1150ms | 流速从 0.35× 提到 1.85×，拖尾加长 |
| Red Shift | 1150–1600ms | 每条光轨按 `red*1.9 - idx*0.16` **依次**转红 |
| Dissolution | 1600–2050ms | 线宽收细 72%，沿轨迹出现断口，alpha 渐降 |
| Reveal | 2050–2400ms | 整体 alpha 归零，遮罩移除 |

调色：`#FFC698`（金）→ `#EF8E75`（珊瑚）→ `#D94A46`（朱）→ `#B92F3D`（绯）。

## 4. 行为验证

| 场景 | 结果 |
|---|---|
| 首次冷启动进入首页 | 播放一次 |

## 6. 已知限制

1. **原生 TabBar 遮不住**：遮罩是页面内的 fixed 层，底部 tabBar 是原生组件，
   动画期间仍然可见（截图里能看到）。这是小程序限制，不是 bug。
2. **真机帧率未测**：模拟器 118fps 不代表真机；真机大概率锁 60fps。
3. **"跳过"位置**在右下，与 tabBar 有些接近，尚未做安全区的真机校准。
4. 动画期间页面内容已正常初始化，但遮罩是全屏不透明——用户看不到底层加载，这是有意的。
