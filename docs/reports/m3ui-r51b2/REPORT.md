# M3-UI-R5.1-B2 · 无边界局部光学场

---

## 1. 换掉了什么

上一版把"光"画成**深灰线**，所以是线稿。这一版换成三层光学：

| 层 | 做法 | 为什么这样能看见 |
|---|---|---|
| **Ambient Field** | 以光环为中心、半径 0.46×短边、五档渐变的**圆形**暖场，边缘归零 | 近白纸上没有"更亮"的余地，只能让局部略暗，光才有对象 |
| **Translucent Filaments** | 3 条主轨 + 5 条极轻辅助轨，颜色是**近白** `rgb(252,252,248)` | 白丝压在略暖的场上 → 丝比"它所在的底"更亮，这才是光 |
| **Energy Highlights** | 两个交点各一团近白径向光 | 亮部只出现在交汇，不铺满 |

关键测量口径也换了：不再比"和整页纸的差"，而是比"丝与其局部场的差"。

## 2. 一个必须记下的坑

第一次实现时，`createRadialGradient(... outer = min(W,H)*0.98)` 加 `fillRect`，
渐变半径超过了画布 → **画布边缘仍有颜色**，屏幕上出现一个清晰的浅色矩形。

修复：半径收到 `0.46 × 短边`，并用 `arc` 填充圆形区域，渐变在自己的边界处 alpha 为 0。
**光场的边界必须是数学上的零，而不是靠画布裁掉。**

## 4. B2-2 为什么失败

我把场和丝烘焙成 720×720 的透明 PNG（`design/f39r8b/base-*.png`），
Canvas 只负责流动高光。但**基底的圆心与 Canvas 的 `cy` 不在同一位置**，
基底按 `aspectFit` 铺满一个宽扁容器，结果光环比画布里的丝偏上、偏大，
两层叠成一团糊掉的暖色雾。截图 `B2-2.png` 就是失败现场。

**我没有把它调一调就当成功**。若要继续，正确做法是让基底与画布的圆心/半径共用同一组参数，
或干脆放弃图片基底、全部用 Canvas ——那需要在下一轮单独做。
