## 4. 真机测试记录规范（防「截图冒充运行」）

每个 `VERIFIED` 状态必须附一条记录，包含：

| 字段 | 要求 |
|---|---|
| 设备 | 型号 + 系统版本（如 `MacBookPro18,3 / macOS 27.0.1`） |
| 构建 | git commit + 构建号 + 是否 release |
| 操作 | 实际点击路径（逐步） |
| 观察 | 屏幕录制或连续截图，含系统时间 |
| 指标 | 若涉及性能，附 `ps`/活动监视器数值 |
| 失败记录 | 失败也要记，且不得删 |

**明确禁止**：
- 用设计稿或静态截图标注为「已运行」
- 用单机模拟双端流程（A06/A07 必须两个独立客户端）
- 用 `localhost` 结果标注为「线上可用」
- 用 mock 数据截图标注为「光场已上线」
