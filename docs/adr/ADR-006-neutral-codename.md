# ADR-006 · 代码使用中性代号 `firstlight`

- **状态**：已采纳
- **决议来源**：D-05
- **论证背景**：产品文档 §3.1（正式品牌名称尚未确定，不得固化）

## 决策

1. 代码标识统一 `firstlight` / `first-light`（crate 名、包名、目录名）。
2. **用户可见的品牌文字不得硬编码**，全部来自单点配置
   （F1 阶段尚未建立 `brand.json`，属于 F2 事项；F1 只保证不写死）。
3. 中转/占位域名使用 `example.invalid`（RFC 2606 保留域名），
   避免误用真实域名与商标。

## 后果

- 正式品牌确定后，改名成本 = 改一处配置 + 换图标 + 改仓库/包名，不触碰业务逻辑。
- 不允许在代码中出现「SPARK」「光场」等候选名作为标识符（避免商标风险扩散）。
