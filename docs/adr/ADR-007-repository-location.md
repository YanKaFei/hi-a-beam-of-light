# ADR-007 · 仓库位于 `first-light/`，独立 git 仓库

- **状态**：已采纳并执行
- **决议来源**：D-01
- **日期**：2026-10-31

## 背景

F0 审计发现：工作区根目录 `/Users/coffee/Desktop/创造一切可能` **不是 git 仓库**，
其中容纳 40+ 个互不相关的项目（ARTEX、flowback、SmartStaff-AI 等）与临时目录。
它同时是多个项目的共享草稿区。

## 决策

1. 在 `first-light/` 内 `git init`，作为本产品唯一仓库。
2. **不修改、不删除、不迁移工作区中其他任何项目。**
3. F0 已交付的 10 份设计文档纳入版本管理。
4. `.gitignore` 显式排除：密钥、本地数据库、用户数据、构建产物、
   以及任何 `*.sqlite`（本机真实数据永不入库）。

## 纳入与排除的具体口径

| 纳入版本管理 | 排除 |
|---|---|
| 源码、测试、共享夹具、JSON Schema | `*.sqlite` / `*.db`（真实数据库） |
| `data/model-registry.v1.json`（公开字典） | `.env*`、`*.pem`、`*.key`、恢复码 |
| ADR、设计文档、审计与测试报告 | `target/`、`node_modules/`、临时目录 |
| 探针脚本（不含真实数据） | 任何含本机路径或用户内容的文件 |

## 后果

- 仓库自包含，可独立 clone / 构建 / 测试。
- 工作区其他项目的状态完全不受影响（已核对：仅新增 `first-light/`）。
- 代价：本仓库与工作区其他项目不共享依赖缓存；Rust 与 npm 缓存被显式重定向
  （见 [00-environment-audit.md](../00-environment-audit.md) §6）。
