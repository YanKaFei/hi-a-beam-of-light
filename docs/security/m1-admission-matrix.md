# 可信来源准入矩阵

| 来源类型 | 保存 | 计入称号 | 可用于激活 | 计入公共光场 |
|---|---|---|---|---|
| `UNSIGNED_CLAIM` | 是 | 否 | 否 | 否 |
| `SIGNED_SELF_CLAIM` | 是 | 是（仅本地展示口径） | **否** | **否** |
| `PLUGIN_OBSERVED` | 是 | 是 | 是（需挑战绑定） | **否** |
| `INDEPENDENTLY_CORROBORATED` | 是 | 是 | 是 | 是 |

## 默认政策

**新增的开放插件自签记录不得直接触发公开网络可信激活。**
`SIGNED_SELF_CLAIM` 无论签名多么正确，`activate` 恒为 `false`。

## 为什么这样切

- 保存与展示：风险为零，用户自己的记录。
- 计入称号：影响只在本机可见，用户骗自己无意义。
- 激活：会让另一个人收到"你被点亮了"的回响——**这是对外承诺**，必须有比自述更强的依据。
- 公共光场：会变成对外数字，必须能被独立佐证。

## 能力限制（明说）

`INDEPENDENTLY_CORROBORATED` 目前**没有任何达成路径**，所以公共光场在 M1 之后仍然不增长。
这不是 bug，是不愿意用"看起来热闹"换掉证据规则。
