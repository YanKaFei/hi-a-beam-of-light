## 2. L3 透明与材质专项

**方案变更**：不再用"预合成到背景色"，改为**直通 alpha（straight alpha）+ 径向遮罩**，
遮罩在半径 65% 起淡出，保证边缘 alpha 归零。

像素级验证（同一张 480px 资产分别叠到三种底色）：

| 底色 | 角点像素 | 中心像素 |
|---|---|---|
| 暖瓷白 `#F6F7F4` | **(246,247,244)** 与底色完全一致 | (179,139,118) |
| 浅纸 `#EEECE5` | **(238,236,229)** 一致 | 同上 |
| 深色 `#1E2022` | **(30,32,34)** 一致 | 同上 |

→ 无暖白矩形、无径向色圈、bloom 未被截断、主体轮廓完整。
局部放大见 `docs/reports/m3ui/light-zoom.png`。

**结论**：这是一张可用于任意背景的真 alpha 资产，不再受背景色限制。
