# Ollama 插件边界（评估，未开发）

## 只做什么

- 作为用户与本地 Ollama 之间的**显式代理**，只观察经过它的请求。
- 在**确认收到完整响应**之后才记录一条观察事件（不是发出请求时）。
- 记录：模型名、开始/结束时间、token 计数（若可得）、adapter 版本。
- 用设备密钥对凭证签名，`source_type = PLUGIN_OBSERVED`。

## 不做什么

- 不保存、不上传提示词与模型响应正文。
- **不因为用户装了 Ollama 就产生任何凭证**——必须有经过代理的真实请求。
- 不把本地代理的观察包装成远程可信证明。
- 不读其他应用的数据库或缓存。

## 工程边界

| 项 | 要求 |
|---|---|
| 监听地址 | **只绑 `127.0.0.1`**，绝不绑 `0.0.0.0` |
| 认证 | 本地代理需要一次性 token，防止本机其他进程白嫖 |
| 端口 | 冲突时可换端口，用户可配置 |
| 异常退出 | 不得留下半条凭证；写盘前崩溃 = 没有凭证 |
| 日志 | 默认只记元数据；**禁止**把 prompt/response 写进日志 |
| 卸载 | 凭证随密钥撤销失效 |

## 诚实声明

即使插件完全按上面实现，它仍然只是"用户机器上的一个观察者"。
用户改了插件、或伪造整个代理，服务端无法分辨。这决定了它的上限是
`PLUGIN_OBSERVED`，永远不是 `INDEPENDENTLY_CORROBORATED`。
