# 一束光 · 配乐 01

本次为程序化原创器乐合成，没有使用现成商业歌曲、外部生成模型或人声。声音由柔和键音、暖垫音和轻铃音构成。原始编曲见 compose.py 与 score.json。

- opening.mp3 / opening.wav：17.6 秒，供开场使用。0–4.8 秒暖垫与稀疏键音跟随光环；4.75 秒收拢提示；6.9 秒点亮接收方；9.65–10.1 秒光场展开；14.6 秒欢迎尾音。尾部 1.5 秒淡出。
- bgm.wav：32 秒，页面内循环使用；低音量、没有鼓组。生成时将跨越循环边界的音符与反射尾音环回，供无压缩 WAV 循环播放。bgm.mp3 为便于单独试听的压缩副本。
- 网页音量：开场 72%，BGM 22%。浏览器初始静音；开场左上角“有声重播”会从头同步播放；顶部背景音乐开关可随时停止。
- 画面以开场音频 currentTime 为主时钟；切后台时暂停，回到前台继续。跳过开场立即停止开场音轨，改播界面 BGM。

检测：17.6 秒 MP3 解码峰值约 -8.4 dBFS、平均电平约 -22.0 dB；32 秒 WAV 峰值约 -8.0 dBFS。以上为 ffmpeg volumedetect 实测，不是 LUFS 响度值。未发现数字削波。

验证：声音开关/拒绝播放回退的两个单元测试通过；浏览器中开场音频 readyState 4、paused false、时间前进；跳过后 BGM loop true 且 paused false；关闭后两音轨均暂停。未声称完成耳机/扬声器听感混音验收，也未在微信真机接入音频。

设计参考：导演库《音乐什么时候不该推动事件》的“画面事件先成立，音乐再加分”；音乐技能 music-director 的旋律、和弦、事件音、留白分工。具体音符及音色由本次程序合成。

重制：运行 python3 compose.py，会将 WAV 和 score.json 保存到本脚本所在目录；需要 Python 3 标准库。MP3 使用 ffmpeg 转码。
