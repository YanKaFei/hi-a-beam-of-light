# 第一束光 · 本地验收版

启动：双击 `启动测试页.command`（需要 Python 3），保留启动窗口。浏览器打开 http://127.0.0.1:8896/ 。

也可以在此目录运行：

```sh
python3 preview_server.py --port 8896
```

测试入口：

1. 开场：光环、字幕、传光寓意；左上角“有声重播”开启配乐，首页顶部控制 BGM。
2. 我的光：选择模拟工具查看光色。工具识别仍是演示，没有真实扫描电脑。
3. 传光：生成邀请二维码、复制链接、撤销；点击“预览传光动效”检查视觉效果。
4. 地图：世界/中国/上海快捷切换，缩放拖动；点“标注地点”，再点地图添加私人标注，点击标注可删除。

邀请接收需要运行本地 API。它使用独立访客身份与 SQLite，不是正式微信账号。127.0.0.1 二维码不能被其他手机访问，正式跨手机还需可共同访问的服务地址。当前 NFC 入口仅提供说明，未接入标签读写。详见《传光与地图更新.md》。

地图使用真实 OpenStreetMap 底图，需要联网，署名须保留；地图已有光点是演示，自己添加的标注只保存在当前浏览器。底图请求失败可重载。尚未发布真实附近用户位置。

配乐为代码原创合成，详见 audio/音乐说明.md。浏览器开场与小程序工作副本曾同步绘图源码；本次新增的二维码后端、地图标注、传光动效与音频播放只接入浏览器验收版，微信真机仍待开发和测试。
