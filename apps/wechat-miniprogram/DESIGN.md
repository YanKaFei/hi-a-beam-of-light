# Editorial Light 2.0 · 设计说明

## Tokens（`app.wxss` 中是唯一来源）

| token | 值 | 用途 |
|---|---|---|
| `--canvas` | `#F6F7F4` | 全站底色（暖瓷白） |
| `--ink` | `#202825` | 主文字 |
| `--ink-2` | `#66716B` | 说明文字 |
| `--ink-3` | `#8A938D` | 辅助/时间戳 |
| `--terracotta` | `#A96B5B` | 唯一强调色（主操作、警示） |
| `--rule` | `#D8DCD3` | 发丝分隔线 |
| `--warm` | `#E7D4BF` | 暖高光（当前未大面积使用） |

## 构图

- 外边距 48rpx，顶部按 `statusBarHeight` 让位（自定义导航）。
- 主视觉：首页 300rpx 光核居中偏上，其余页以文字为视觉重心。
- 用**发丝线与留白**组织信息，不用卡片、不用阴影、不用彩色 badge。

## 导航

底部三栏：**我的光 / 传光 / 回响**。
连接插件、光路、设置在**上下文入口**进入：首页底部 `光路 · 设置`，首页主操作进入「连接插件」。
六个页面全部可达，功能未删。

## 可信状态的表达

三个维度分开呈现，不做七级进度条：

1. **设备**：未连接 / 已连接（首页「设备」行）。
2. **证据**：展开区显示 `已签名 · 未获独立核准`，并有一句解释签名不等于真实使用。
3. **传光**：传光页只说明流程；没有独立核准就不出现"已点亮"。

## 动效

仅两处：光核 9s 极轻呼吸（`prefers-reduced-motion` 关闭）；页面进入的内容渐显由微信默认转场承担。
没有粒子、没有 WebGL、没有成功激活动画。
