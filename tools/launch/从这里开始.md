# 从这里开始 · 看一束光

## 打开浏览器验收版

双击本目录的 **启动测试页.command**，会自动打开 <http://127.0.0.1:8897/>。
保留启动窗口；按 Control+C 停止。只需要 Python 3，不必安装 Node 依赖。

如果 macOS 用编辑器打开了 command 文件，也可以在仓库根目录运行：

```sh
python3 tools/launch/launch_preview.py
```

浏览器版是模拟体验：开场、我的光、传光二维码、真实地图与私人标注都能点，
但**不会扫描你的电脑**。要体验真实扫描，需要编译桌面端（见仓库 README 的快速开始）。

## 本地生成的文件

- 访客数据库：`tools/launch/.local/preview.sqlite`（已加入 .gitignore）
- 地图需要联网；标注只保存在当前浏览器
- localhost 的二维码不能被另一台手机访问

## 仓库结构

| 目录 | 内容 |
| --- | --- |
| `design/healing` | 疗愈界面：原型、设计说明、四语言出图脚本 |
| `apps/browser-preview` | 浏览器验收版：开场、传光、地图、动效 |
| `apps/desktop` | Tauri 桌面端：透明悬浮光点 + 四屏面板 |
| `apps/wechat-miniprogram` | 原生微信小程序源码 |
| `services/api` | 传光服务端：邀请、确认、激活、回响 |
| `crates` / `packages` | Rust 核心、适配器、本地存储、协议与共享数据 |
| `docs` | 架构、12 份 ADR、隐私与验收报告 |
