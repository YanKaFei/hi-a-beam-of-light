# hi，一束光

当前开发工程整理于 2026-11-05。

## 打开测试页

双击顶层的 **启动测试页.command**，会启动并打开 http://127.0.0.1:8897/ 。保留启动窗口；按 Control+C 停止。需要 Python 3，无需先安装 Node 依赖即可体验浏览器版。

若 macOS 用编辑器打开 command 文件，可在终端进入本目录运行 `python3 launch_preview.py`。

| 目录 | 内容 |
| --- | --- |

`first-light/.git` 保留原仓库历史；本次修改以未提交状态保留，方便审查。源码及锁文件已包含，依赖与编译缓存可按工程 README 重新安装和生成。

## 当前完成边界

浏览器验收版是本次交互更新最完整的入口；小程序及桌面端尚未同步全部浏览器功能。Android/iOS 独立安装包、Windows 真机验证、真实微信登录、NFC 标签读写和正式公网部署仍待完成。

二维码邀请使用独立的本地访客服务及 SQLite，不等于正式账号或 AI 使用点亮。localhost 链接不能供另一台手机直接访问。真实地图需要联网；地图现有光点是演示，私人标注只保存在本浏览器。详见 browser-preview/传光与地图更新.md。

本地启动产生的访客数据库放在顶层 `.local/`，未随本次源码复制。
