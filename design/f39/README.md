# F3.9 品牌光学符号研究

**设计研究，未修改生产代码。** `apps/desktop/ui/`、`tokens.json`、`paintBead` 均未触碰。

九候选 · 六尺寸 · 两种底色 · 复杂壁纸 · 页面实尺寸 · 七状态 · 三段动效。

---

## 1. 三个方向，九个候选

| 方向 | 候选 | 形态 | 想表达 |
|---|---|---|---|
| **A 光隙** | A1 竖缝 | 极窄的竖向开口，中间一道光 | 光从缝里漏出来——不是有光，是光在穿过 |
| | A2 六叶光圈 | 六片叶片围成六边形，中心一点光 | 光圈开合 = 累积；孔径大小可承载等级 |
| | A3 三层百叶 | 三道错位的横向缝 | 层叠 = 多次使用；斜向出光 |
| **B 光种** | B1 水滴 | 泪滴，光在尖端 | 一粒光的种子，会长大 |
| | B2 子叶 | 豆形，内弧一道光 | 胚芽/内部生长 |
| | B3 种托 | 一点光坐在开口的杯里 | 被托住的光——接收/被接住 |
| **C 裂环** | C1 缺口 | 环缺一角，缺口最亮 | 光从破碎处溢出 |
| | C2 三片 | 三段不等长弧，半径略错 | 碎片化，更抽象 |
| | C3 双弧 | 两个同心半弧错开旋转 | 分离与回响 |

三者语义各不相同：A 是**通道**，B 是**生长的实体**，C 是**破损与回声的容器**。

## 2. 尺寸实测（`out/matrix.png`）

判据：16 / 24 px 下能否只看轮廓认出。

| 候选 | 16px | 24px | 32–96px | 结论 |
|---|---|---|---|---|
| A1 竖缝 | 一道竖线 | 可辨 | 96px 会读成"咖啡豆" | 小尺寸好，大尺寸语义漂移 |
| **A2 六叶光圈** | 可辨（六边形） | **优秀** | 稳定 | 全尺寸最稳 |
| A3 百叶 | 糊 | 弱 | 96 像"列表图标" | 淘汰 |
| **B1 水滴** | 可辨 | **良好** | 稳定 | 语义与形态都成立 |
| B2 子叶 | 黑块 | 弱 | 内弧光在 32 以下消失 | 淘汰 |
| B3 种托 | 一个点 | 一般 | 像"笑脸" | 偏可爱，不符 B+ |
| C1 缺口 | 可辨 | 良好 | 与加载圈高度相似 | 辨识但易误读 |
| C2 三片 | 不可辨 | **不可辨** | 44 起才有形 | 淘汰（太稀疏） |
| C3 双弧 | 不可辨 | 不可辨 | 44 起勉强 | 淘汰（小尺寸失效） |

**24px 是分水岭**：A2、B1、C1 活下来，其余六个在这个尺寸失去识别度。

## 3. 背景（`out/matrix.png` 下半 / `out/wallpaper.png`）

- 深色底：A1、A2、B1 的暖光在深底反而更清楚；C1 的墨线在深底几乎消失（对比度不足）。
- 复杂壁纸（**合成背景，未读取用户桌面**）：所有候选的暖光都能站住，
  但**只有 A2 的实心轮廓**在彩色噪声上也保持形状；C1 的细环被背景吞掉。
- 这印证了之前的结论：**细线在复杂背景上不可靠，实心块可以**。

## 4. B+ 页面实尺寸（`out/on-page.png`）

44px 下放进「我的光」：
- A2 像一个徽章，安静、有辨识度；
- B1 像一枚水滴徽记，语义好但略"软"；
- C1 的圆环与界面里的 loading / 单选圆点在视觉上撞车。

## 5. 七种功能状态（`out/states.png`）

状态只作用于符号本身（亮度、外环、来光弧），**不触碰称号与证据规则**。

- **A2**：内核亮度变化 + 外环，四档区分清楚，形态不变 → 最稳。
- **B1**：尖端亮度变化，读起来像"点亮"，但"已激活"与"成长"差别偏小。
- **C1**：**已激活时外环闭合成完整圆，把"裂环"的隐喻自己消掉了**。
  这是 C 方向的致命缺陷，不是调参能救的。

## 6. 动效（`out/motion-A2.gif` / `motion-B1.gif` / `motion-C1.gif`）

每段 24 帧 / ~1.7s：点火 → 缓慢呼吸 → 回响外扩。

- 全部由**符号参数**驱动（亮度、环半径），没有粒子、没有流体。
- 可降级：`prefers-reduced-motion` 下停在"点火完成"的静态帧，仍能表达状态。
- 成本：一帧 = 一张 96px 位图的合成；烘焙成雪碧图后，常驻成本与现在的 `paintBead` 同级
  （现有基线：空闲 0.013% CPU / 112 MB）。

## 7. 七个必答问题

| 问题 | A2 | B1 | C1 |
|---|---|---|---|
| 1. 去掉颜色还有轮廓辨识度 | **是**（六边形） | 是（水滴） | 是（带缺口环） |
| 2. 24px 仍成立 | **是** | 是 | 是（但与加载圈混淆） |
| 3. 是否像普通按钮/宝石/玻璃珠 | 略像六角螺母 | 略像定位针 | **像加载圈** |
| 4. 独立品牌特征 | 中（几何感强） | 中（语义强） | 弱 |
| 5. 适用于浅色 B+ | **是** | 是 | 是（对比偏弱） |
| 6. 可延伸为图标/光点/动效/光场节点 | **是**（六边形可做图标底） | 是（种子=节点） | 否（闭合后失去特征） |
| 7. 低资源渲染可实现 | **是**（多边形+单点光） | 是（圆+锥+点） | 是（三段弧） |

## 8. 推荐

**首选 A2（光隙 · 六叶光圈），次选 B1（光种 · 水滴）。**

理由不是审美偏好：

1. A2 是九個候选里唯一在 **16px 到 96px 全程保持同一轮廓**的；其余要么小尺寸糊掉，
   要么大尺寸语义漂移（A1 变咖啡豆）。
2. A2 的**孔径**天然可以承载等级（一档一档张开），而 B1 只能靠亮度，
   亮度在浅底上的可分辨区间很窄。
3. B1 作为次选是因为语义最准——"光的种子"直接对应产品叙事，
   且它比 A2 更像"活物"，适合做桌面光点的呼吸主体。

**明确不推荐 C 方向**：`已激活` 状态会闭合成完整圆环，把裂环的意义抹掉；
且 C1 在复杂壁纸与深底上对比不足。

## 9. 若选 A2，下一轮需要解决

- 六边形的"螺母感"：把六个角的圆角加大、让它更接近花瓣而非机械件；
- 孔径档位需要和五档称号建立**可验证的映射**（一档 → 一个开度）；
- 应用图标、桌面光点、传光动效、光场节点四种用途下的同一套几何参数。
