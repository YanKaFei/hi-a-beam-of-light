## 1. 两套方案的根本差异（不是换色）

| | A · Porcelain Workspace | B · Editorial Light |
|---|---|---|
| 结构 | 176px 侧栏 + 内容区 | 无侧栏，顶部细线导航 |
| 组织 | 白色卡片承载数据 | 细线与字阶组织，无卡片 |
| 主操作 | 赤陶色实心按钮，112×34 | 一行文字 + 手绘箭头，无按钮 |
| 标题 | 17px 常规页面标题 | 38px 社论式大标题 |
| 数字 | 26px 内嵌于统计行 | 58/64px 作为第二声部 |
| 信息密度 | 中高，一屏可读完 | 低，留白承担节奏 |
| 气质 | 精密工具 | 出版物 |

**A 是产品界面，B 是一个观点的表达。** 这是有意为之：两套必须能回答"如果只允许一种性格，你要选哪种"。

## 2. 色彩（起始值，未写入生产）

```
canvas #F6F7F4   surface #FFFFFF   surface2 #ECEEEA   divider #E5E9E6
text   #202B30   text2   #717B80   accent   #A96B5B   accent2 #6F8985
```

使用纪律：
- **赤陶 `#A96B5B` 只给主操作和错误**，一屏最多出现两次；它一旦变成装饰就不再是信号。
- **雾青 `#6F8985` 只给「已核验/已激活」**，与赤陶不混用。
- 文字只有三级，`text3` 仅用于标签与时间戳，不承担正文。

## 3. 字阶（macOS 原生 + 苹方）

| 角色 | 字号 | 字重 | 用途 |
|---|---|---|---|
| 社论标题 | 38 / 34 | W6 | 仅 B 的称号 |
| 页面标题 | 21 / 17 | W6 | 我的光、传光 |
| 数字指标 | 58 / 64 | Avenir Medium | B 的计数 |
| 操作标题 | 13 | W6 | 按钮文字、行标题 |
| 正文 | 12.5 / 12 | W3 | 说明 |
| 状态 | 11.5 | W3 | 状态行、标签 |
| 辅助 | 10.5 | W3、字距 +2.2 | 栏目名（B 的 kicker） |
| 数字小字 | 11 | Avenir Light | 时间、会话数 |

中文用 PingFang（本机取 Hiragino Sans GB 等价），数字与英文用 Avenir / Helvetica Neue：
数字用等宽对齐，避免计数跳动时抖动。

## 4. 组件（`out/components.png`）

应用外壳、侧栏、页面标题区、身份区、主按钮、文字操作、模型行、状态标签、
扫描状态、连接状态、二维码板、传光三态、光路行、回响记录、空态、错误条。

统一规则：
- 圆角：面板 10 / 按钮 8 / 标签 10（全圆角）
- 边框：1px `divider`，不用投影堆叠；A 的卡片只有一层极轻投影（alpha 16）
- 行高：28–44px，行间用 1px 细线分隔，不用斑马纹

## 5. 状态覆盖

`out/A-states.png`、`out/B-states.png`：0 个模型、服务未连接、空记录、权限被拒绝。
错误在 A 里是浅赤陶底条，在 B 里只有一条 1.5px 赤陶线——两套各自成立，不共用一套视觉。

## 6. 取舍

| 选择 | 代价 |
|---|---|
| A 用侧栏 | 720 宽度下内容区只剩 480，长列表会略挤 |
| B 用大留白 | 720×560 里可承载的信息量约为 A 的 60% |
| 数字大字 | B 的计数很漂亮，但超过 4 位会破坏基线 |
| 不用阴影 | 层次全靠边框与底色差，弱屏上对比会更低 |
