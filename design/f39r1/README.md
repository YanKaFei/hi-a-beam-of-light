## 1. 四版对照（`out/matrix.png`）

| 版本 | 定义 | 结论 |
|---|---|---|
| **A2-Original** | 直边六瓣，边角硬 | 24px 可辨，但 96px 读作"六角螺母" |
| **A2-Organic** | 超级椭圆轮廓 + 圆角、缝收进体内 | **轮廓最稳**，从 16 到 96 同形 |
| **A2-Signature** | Organic + 边缘缺口 + 孔径偏心 | 16px 仍有识别线索（缺口），但 96px 略像"裂片" |
| **B1-Seed** | 水滴 | 语义最准，但 24px 以下与"定位针"混淆 |

**两轮失败记录（重要）**：

1. 第一版把六片叶瓣**分缝**画——24px 下缝隙变成噪点，轮廓彻底垮掉。
2. 第二版把孔做成**花瓣形**、缝做成亮线——96px 读作"花"，正是简报禁止的方向。

结论：**轮廓必须是一个实心整体**，"有机"只能放在边角曲率、孔径形状和缝的明度差里。
任何靠缝隙/细线制造的结构，在小尺寸都会失效。

## 2. 几何参数模型

```
body   = 超级椭圆 |x|^n+|y|^n=1，n=3.45（Original 6.0 接近六边形），旋转 15°
hole   = 玫瑰线 r(θ)=r0·(1+k·cos6θ)，k=0.045（Signature 0.065）
r0     = R·(0.13 + 0.50·tier)          R = 0.355·边长
notch  = 顶角 26°、深度 0.20R 的三角缺口，方位 38°+
seams  = 体内亮 8% 的发丝线，仅 ≥32px 绘制（小尺寸直接丢弃）
```

## 3. 五档孔径（`out/tiers.png`）

| 称号 | 家族数 | tier | r0/R |
|---|---|---|---|
| 寻光者 | 0 | 0.10 | 0.18 |
| 初明者 | 1 | 0.26 | 0.26 |
| 启迪者 | 2–3 | 0.48 | 0.37 |
| 探索者 | 4–6 | 0.70 | 0.48 |
| 拓界者 | 7+ | 0.90 | 0.58 |

- **非线性**：档间步长不等（0.16 / 0.22 / 0.22 / 0.20），低档更密，让"0→1"是明显的一跳。
- **最高档 r0=0.58R**，本体仍留 42% 边宽，轮廓不会消失。
- 灰度版一并给出：**档位不依赖色相**。
- E2 自主确认不改 tier —— tier 只由 `verified_families` 决定，与现有规则完全一致。

## 4. 必须先说清的缺陷

**五档在小尺寸上区分不了。** 实测：

- 96px：五档可辨。
- 44px：相邻档勉强可辨，隔档可辨。
- 24px：**全部退化为"深色圆点 + 亮点"，档位不可辨**。

这不是调参能解决的——孔径从 0.18R 到 0.58R 的变化，在 24px 里只有 4–5 个像素。
**所以称号必须继续由文字（"初明者 / 启迪者"）承担，符号不承担读档职责。**
如果要求符号本身在 24px 报档，就得改用完全不同的编码（例如外环分段数），那会破坏轮廓。

同理，七种业务状态在 56px 缩略下差异偏弱：`未点亮 / 首个点亮 / 成长` 三者主要靠亮度，
而亮度在浅底的可分辨区间很窄。**这是本轮最重要的负面结论。**

## 5. 传光与外来的语义（`out/states.png`）

| 状态 | 内部 | 外围 | 是否改变自身等级 |
|---|---|---|---|
| 未点亮 | 孔径最小、光弱 | 无 | 否 |
| 首个点亮 | 孔径一档 | 无 | 否 |
| 成长 | 孔径随档 | 无 | 否 |
| 收到来光 | 自身不变 | **左上弧形来光**（暖赤陶） | **否** |
| 等待激活 | 自身不变 | **灰色空心环**（未闭合） | 否 |
| 已激活 | 自身不变 | **完整赤陶环** | 否 |
| 回响 | 自身不变 | **两道外扩弧** | 否 |

关键约束的实现方式：
- **RECEIVED 不表现为激活**：来光只是左上角一段弧，环不闭合、不加粗。
- **LEARNING 不伪造新增**：等待态用灰色虚环，孔径不动，不产生新档。
- **ACTIVATED 只由服务端**：原型里它只是一个渲染分支，没有计时器推进；生产状态机未改。
- **传光不缩小自身孔径**：发送方在所有传光状态下 tier 不变（表中"否"列）。

## 6. 动效（`out/motion-sequence.gif`）

七拍各一：点火 → 呼吸 → 分离 → 来光 → 等待 → 激活 → 回响。
全部由几何参数（tier / lit / 环半径）驱动，无粒子、无模糊层。
`prefers-reduced-motion` 的替代：`out/motion-reduced-static.png`（停在"点亮完成"帧，
状态仍可读，不需要动画）。

## 8. 品牌识别检查（诚实版）

与常见形态对比：

| 参照 | 相似度 | 判断 |
|---|---|---|
| 相机光圈快门 | 中高 | 六瓣结构天然接近；靠"缺口 + 非对称"拉开，**但仍有风险** |
| 六角螺母 | 中（Original 高） | Organic 的圆角已基本消除 |
| 设置齿轮 | 低 | 无齿 |
| 花朵 | 中（第二版） | 已修正为低幅孔径 |
| 加载圈 | 低 | 无闭合环 |

**坦率结论：A2-Signature 仍然读得出"光圈"。** 缺口让它不像机械件，但没有让它脱离"光圈"这个大类。
如果要求完全脱离，需要再换一套编码（例如非中心对称的开口），那会牺牲小尺寸稳定性。

## 9. 性能与实现成本

- 静态：一个多边形 + 一个玫瑰线多边形 + 2 层辉光，**可预烘焙为 6 个尺寸的雪碧图**，
  常驻成本与现有 `paintBead` 同级（基线：空闲 0.013% CPU / 112 MB）。
- 动效：每帧只是参数重绘；烘焙成序列帧后只做贴图。
- 难度：**低**。无 shader、无粒子、无模糊滤镜依赖。

## 10. 推荐

**首选 A2-Signature，次选 A2-Organic。**

- Signature 的缺口是唯一在 16px 还存在的品牌线索，这是"独特身份"的实际抓手；
- 若评审认为缺口太"裂"，退回 Organic —— 它轮廓最干净，代价是 24px 以下与普通圆点无异。

**明确不建议把 tier 当作视觉主编码**（见 §4）：它能表达"成长"，但只有在大尺寸成立。
