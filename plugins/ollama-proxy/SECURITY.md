# 本地代理安全说明

| 风险 | 防护 |
|---|---|
| 恶意网页调用本地端口 | 要求 Bearer token；带 `Origin` 头的请求一律 403 |
| DNS rebinding | 校验 `Host` 必须是 loopback，否则 421 |
| CORS 误用当作边界 | CORS **不是**边界；边界是 token + Origin 拒绝 |
| 端口被他人占用/滥用 | 默认端口可改；token 每次随机生成 |
| 局域网暴露 | 只 `listen('127.0.0.1')` |
| 请求体过大 | 上限 8 MB，超出 413 |
| 异常退出 | 进程退出即关闭监听，无残留服务 |
| 未授权路径 | 只暴露两个 API 路径，其余 404（鉴权先于路由，避免泄漏路径存在性） |
