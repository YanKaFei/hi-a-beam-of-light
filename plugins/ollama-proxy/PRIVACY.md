# 隐私说明

代理在转发时**技术上必然接触请求与响应正文**。任何"完全看不到你的内容"的说法都是假的。

事实是：

| 阶段 | 是否接触正文 |
|---|---|
| 转发（内存中） | 是，无法避免 |
| 解析完成事件 | 只解析 `done` / `model` / `eval_count` 字段 |
| 日志 | **否**（只记事件类型与家族） |
| 凭证 | **否**（字段白名单：family / adapter / 时间 / 观察方式） |
| 磁盘 | 不落盘 |
| 上传 | 只有凭证，不含正文 |

不持久化：prompt、messages、response、thinking、聊天历史、第三方 API Key、原始报文、文件路径。
